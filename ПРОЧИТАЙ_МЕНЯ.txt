ИИ ЧАТ — МОДЕЛИ НА ТЕЛЕФОНЕ

ДЛЯ УСТАНОВКИ
1. Скачай отдельно AI_Chat_Models.apk и открой файл в «Загрузках».
2. Нажми «Установить». Если телефон спросит, разреши установку из этого
   источника. Приложение подписано локально, оно не опубликовано в Google Play.
3. Открой «ИИ Чат», нажми «Модели» и выбери, как добавить модель.

ЭТО ОТДЕЛЬНОЕ ПРИЛОЖЕНИЕ. Оно установится рядом со старым «Qwen Чат» и не
удалит его. История и модель из старого приложения автоматически не
перенесутся: Android хранит данные приложений раздельно. Если нужна прежняя
модель в новом приложении, выбери «Скачать исходную Qwen 1.5B (~1 ГБ)».

СПОСОБ 1. ИЗ ФАЙЛОВ ТЕЛЕФОНА
• «Модели» → «Выбрать GGUF из файлов телефона» → выбери файл → «Добавить».
• Приложение скопирует модель в своё хранилище и попробует запустить её.
  Исходный файл останется на месте. Для копирования нужно дополнительное
  свободное место примерно размером с модель. После успешного добавления
  при желании можно самостоятельно удалить исходную копию через «Файлы».

СПОСОБ 2. ПО ССЫЛКЕ
• «Модели» → «Скачать по ссылке / Hugging Face».
• Вставь https-ссылку на сам файл .gguf или на публичный репозиторий модели
  на Hugging Face. Для страницы репозитория покажется список одиночных GGUF
  с размерами. Выбери файл и подтверди загрузку. Можно также вставить ссылку
  на страницу отдельного GGUF-файла с Hugging Face.
• Скачивай модели только из источников, которым доверяешь. Если для файла
  получены размер и SHA-256 из Hugging Face, приложение проверит их. Для
  произвольной ссылки контрольной суммы может не быть — приложение проверит
  только формат и, если известен, размер файла.
• При прерванной загрузке файла с известными размером и SHA-256 снова выбери
  ту же модель: приложение попытается продолжить. Без этих данных придётся
  начать загрузку заново. Пункт «Удалить незавершённые загрузки» в меню
  освобождает место, занятое недокачанными файлами.

КАК ПЕРЕКЛЮЧАТЬ И УДАЛЯТЬ МОДЕЛИ
«Модели» → «Мои модели» → выбери нужную → «Запустить эту модель».
В том же меню можно удалить копию модели из приложения. Исходный файл в
«Загрузках» и переписка не удаляются. При переключении сохраняется текущий
чат; новая модель получает до двух последних обменов сообщениями.

ОГРАНИЧЕНИЯ
• Подходят только совместимые одиночные GGUF-файлы текстовых чат-моделей,
  которые поддерживает включённый llama.cpp b10435. Не каждая модель GGUF
  совместима с движком, и не каждая умеет хорошо отвечать по-русски.
• Это не универсальный запуск любых ИИ. Онлайн-сервисы и модели изображений,
  аудио, файлы safetensors, разбитые GGUF и отдельные vision-адаптеры не
  поддерживаются. Нужны модели Instruct/Chat в одном файле .gguf.
• Модели должны помещаться в память телефона; чем больше файл, тем выше
  потребность в ОЗУ. Для первого опыта попробуй около 1–1,5 ГБ или меньше.
  На телефоне с небольшим объёмом ОЗУ модель может не запуститься. Ответы
  могут быть медленными и содержать ошибки или отказы.
• Android 9 или новее, 64-битная система ARM (arm64-v8a). Рекомендуется
  актуальный Android System WebView. Для загрузки нужен интернет; после
  успешной загрузки или копирования чат может работать без интернета.
• Публичные репозитории Hugging Face поддерживаются без входа; закрытые или
  требующие подтверждения доступа не загрузятся. Ссылки допускаются только
  по HTTPS. Приложение не включает модели в APK.
• При удалении этого приложения его история и модели удалятся. Временные
  и прежние приложения хранят свои данные отдельно.
• Приложение не проверено на конкретном телефоне. Движок Android ARM64,
  модели Qwen и SmolLM2, импорт, скачивание, докачка и переключение проверены
  в тестовой среде; это не заменяет установку на устройстве.

ДЛЯ РАЗРАБОТЧИКА
Исходники находятся в src/, интерфейс — assets/index.html, Android ARM64
библиотеки llama.cpp — в native/arm64-v8a/. Модели в проект не включены.
На Linux нужны JDK 11+, Android SDK Platform 34 и Build-Tools 34.0.0.
Укажи ANDROID_SDK_ROOT и выполни: bash build_apk.sh
Результат: build/AI_Chat_Models.apk. Скрипт создаёт собственный ключ подписи;
пересобранный APK с другим ключом не установится как обновление той же версии.
Сохраняй свой ключ надёжно; при переустановке с удалением данные сотрутся.
