# ИИ Чат для Android

Локальный чат для совместимых текстовых моделей GGUF на Android ARM64. Можно выбрать скачанный GGUF-файл, добавить модель по HTTPS-ссылке или выбрать файл из публичного репозитория Hugging Face. Модели сохраняются на телефоне; после их загрузки интернет для переписки не нужен.

## Скачать и установить

**[Скачать AI_Chat_Models.apk](https://github.com/Mihail007p/Ai-apk/raw/refs/heads/main/AI_Chat_Models.apk)**

1. Скачайте APK на телефон и откройте его из «Загрузок». При необходимости разрешите установку из выбранного источника.
2. Откройте «ИИ Чат» → **Модели**. Выберите GGUF-файл или загрузите модель по ссылке.
3. Для переключения используйте **Модели → Мои модели → Запустить эту модель**.

Модели в APK не включены. При выборе локального файла приложение копирует его в своё хранилище: понадобится дополнительное свободное место примерно по размеру модели.

## Ограничения

- Android 9+ и 64-битная система ARM (`arm64-v8a`).
- Поддерживаются **совместимые одиночные GGUF-файлы текстовых чат-моделей**, но не любые модели ИИ. Модели изображений/аудио, `.safetensors`, многотомные GGUF и отдельные vision-адаптеры не поддерживаются.
- Размер модели должен соответствовать доступной памяти телефона. Начните с небольшой модели; ответы могут быть медленными или содержать ошибки.
- При удалении приложения его локальные модели и переписки удаляются. Данные старого приложения «Qwen Чат» автоматически не переносятся.
- APK не проверен на конкретном телефоне. Движок ARM64, загрузка, переключение и несколько моделей проверены в тестовой среде.

Подробнее: [ПРОЧИТАЙ_МЕНЯ.txt](ПРОЧИТАЙ_МЕНЯ.txt).

## Сборка

На Linux нужны JDK 11+, Android SDK Platform 34 и Build-Tools 34.0.0:

```bash
export ANDROID_SDK_ROOT=/путь/к/android-sdk
bash build_apk.sh
```

Результат: `build/AI_Chat_Models.apk`. Сценарий создаёт локальный ключ подписи. Собранный с другим ключом APK не сможет обновить установленное приложение без удаления старой версии; удаление сотрёт её данные. Ключ подписи опубликованного APK в репозиторий **не входит**.
